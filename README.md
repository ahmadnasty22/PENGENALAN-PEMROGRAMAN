## Tentang Mata Kuliah

**Pengenalan Pemrograman** merupakan mata kuliah yang mempelajari dasar-dasar pemrograman dan cara menyelesaikan suatu permasalahan menggunakan program.

Dalam mata kuliah ini, mahasiswa diperkenalkan dengan konsep dasar pemrograman seperti variabel, tipe data, operator, percabangan, perulangan, fungsi, struktur data sederhana, serta pengolahan data.

Selain memahami konsep, mahasiswa juga dilatih untuk menerapkan logika pemrograman melalui berbagai latihan dan tugas. Proses pembelajaran dilakukan dengan membuat program sederhana hingga project yang menggabungkan beberapa konsep pemrograman.

Beberapa konsep yang dipelajari dalam mata kuliah ini meliputi:

- Variabel dan tipe data
- Input dan output
- Operator aritmatika dan logika
- Percabangan (`if`, `elif`, `else`)
- Perulangan (`for` dan `while`)
- Function dan parameter
- List, tuple, dictionary, dan set
- String dan pengolahan teks
- Pengolahan file
- Penggunaan file CSV
- Error handling
- Penerapan logika dan algoritma
- Pembuatan program sederhana

Mata kuliah ini menjadi salah satu dasar untuk memahami pemrograman lebih lanjut dan membantu mahasiswa membangun kemampuan berpikir logis serta menyelesaikan masalah secara sistematis menggunakan kode.

## PROJECT UAS

Project UAS pada mata kuliah **Pengenalan Pemrograman** adalah **Financial Tracker**, yaitu program berbasis Python yang digunakan untuk membantu pengguna mencatat, mengelola, dan memantau pemasukan serta pengeluaran secara sederhana.

Project ini dibuat sebagai penerapan dari berbagai konsep pemrograman yang telah dipelajari selama perkuliahan, seperti penggunaan variabel, percabangan, perulangan, function, pengolahan data, file handling, dan CSV.

Melalui project ini, pengguna dapat mencatat transaksi keuangan, melihat riwayat transaksi, memperoleh ringkasan keuangan berdasarkan bulan, serta mengekspor data untuk disimpan dalam bentuk file CSV.

### Fitur

1. **Tambah Transaksi**  
   Menambahkan data pemasukan atau pengeluaran beserta informasi terkait transaksi.

2. **Lihat Transaksi**  
   Menampilkan daftar transaksi yang telah dicatat.

3. **Laporan Bulanan**  
   Menampilkan ringkasan pemasukan, pengeluaran, dan saldo berdasarkan bulan tertentu.

4. **Dashboard**  
   Menampilkan ringkasan kondisi keuangan secara lebih sederhana dan informatif.

5. **Export Data CSV**  
   Mengekspor data transaksi ke dalam file CSV sehingga dapat disimpan dan dibuka menggunakan aplikasi spreadsheet seperti Microsoft Excel.

6. **Simpan & Keluar**  
   Menyimpan data transaksi sebelum keluar dari program.
