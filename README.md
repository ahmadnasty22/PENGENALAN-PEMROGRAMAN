# Program Transaksi Sederhana

Program transaksi sederhana yang dibuat menggunakan Python.

## Deskripsi

Program ini digunakan untuk melakukan proses transaksi sederhana,
mulai dari memasukkan data barang, menghitung total harga,
hingga menampilkan hasil transaksi.

## Teknologi

- Python
- Visual Studio Code

## Cara Menjalankan

Pastikan Python sudah terinstall.

Jalankan perintah:

```bash
python transaksi.py
